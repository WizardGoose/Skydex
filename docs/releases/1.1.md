# Skydex 1.1

Skydex brings profiles, recipes, storage, greenhouse planning and shard fusion
together at [skydex.ca](https://skydex.ca).

## Website

- Browse profile gear, accessories, pets, inventory and progression, or look up
  another player without changing the connected account.
- Expand crafting and forge recipes and account for materials already owned.
- Open item details from Profile and minions, then use View in Recipes to carry
  the exact item or minion tier into Recipes, including items obtained without crafting.
- Exclude confirmed admin-only items from accessory progress and recipe choices.
- Load recipes from the wiki's current crafting table after its data-source migration.
- Plan greenhouse targets, solve or edit layouts, and save and share them.
- Plan shard fusions with collection progress, ingredient choices and exclusions.
- Find recorded island-chest contents, positions and individual slots.
- Updated navigation, welcome, settings, documentation and mobile interactions.

## Skydex mod

- Greenhouse placement previews for all 40 mutations and 17 crops. Fifty custom
  head skins ship with the mod; seven crops use native block models.
- Complete 2x2 and 3x3 plant footprints retain their occupied cells and display
  one centred head.
- Native settings and greenhouse interface, saved loadouts, rotation, progress
  comparison and mutation visibility controls.
- Current-board advice is limited to fresh observations in the active world and
  profile. Saved observations remain available for export.
- Existing data migrates to `config/skydex`, with a visible conversion notice.
  Conflicting older files are backed up during migration.
- Legacy snapshot codes remain readable. The mod exports island chests and the
  greenhouse board; API-backed inventory sections remain the website's responsibility.

The mod shows where plants belong. It does not place blocks or automate gameplay.
Full plant assemblies are deferred; 1.1 uses head and native-block previews.

## Downloads and requirements

| Download | Minecraft | Fabric API minimum |
| --- | --- | --- |
| `skydex-1.1+26.1.2.jar` | 26.1.2 | `0.155.2+26.1.2` |
| `skydex-1.1+26.2.jar` | 26.2 | `0.158.0+26.2` |

Both builds require Fabric Loader 0.19.3 or newer and Java 25. Install the JAR
for your exact Minecraft version and its matching Fabric API. Close Minecraft
before replacing an existing Skydex JAR, and keep just one active copy in `mods`.

The website works without the mod and needs no personal Hypixel API key.
For hosted use, import the mod's clipboard export through website Settings.
A locally running site can link to the mod for live updates and layout transfer.

Existing browser settings, plans and texture packs migrate to the Skydex names.
See the [README](../../README.md) and [mod guide](../../mod/README.md) for setup.
